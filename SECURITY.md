# Security Policy

## Supported versions

Security fixes target the latest published Quest VD Wired release.

| Version | Security support |
| --- | --- |
| Latest release | Supported |
| Older releases, including v3.0.1 Legacy | Not supported |

If a report also affects an older version, include that detail. It may help the
maintainer understand the history of the issue, but it does not make that
version supported.

## Report a vulnerability privately

Do not open a public issue or discussion for a suspected vulnerability.

Use the repository's
[private vulnerability reporting form](https://github.com/kkoemets/quest-vd-wired/security/advisories/new).
Include:

- the affected version and component;
- clear reproduction steps or a proof of concept;
- the expected security impact;
- any known mitigations;
- whether the report involves the Windows host, embedded Android app, ADB
  control channel, local diagnostics, packaging, or dependencies.

Do not include real credentials, private keys, personal data, or unnecessary
packet contents. The maintainer will coordinate validation, a fix, and public
disclosure through the private advisory when appropriate.
